## Bricks

- Bring your **Legos** and share with your creations with the class; from starter kits, to Starwars, Harry Potter, and Minecraft, all legos are welcome. 
- **Toybox** is a basic 3D printer that will be availble for everyone to try.

## Blocks

> Please note that a Windows computer is recommended for better Minecraft user experience. 

- **Scratch** is a programming language that uses blocks to represent instructions. It's freely available at https://scracth.mit.edu.  Create an account to save your creations ✅.
- **Minecraft** is a video game where kids can build their own worlds and characters. Buy the [Standard PC Edition](https://www.minecraft.net/en-us/store/minecraft-java-bedrock-edition-pc) ✅. 
- **MCreator** provides an easy experience to extend Minicraft and allows custom programming using blocks, similar to Scratch. Download and install from https://mcreator.net ✅. 

### Bots

- **Micro:bit** is a small board with a simple programming interface. Buy it at [Amazon](https://www.amazon.com/Micro-bit-V2-21-GO-Bundle/dp/B0BJ4HQ63P/) ✅.  

### AI

- **Image Generation** - the free versions of Google Gemini or ChatGPT will be used to generate images for the games.
- **Chatbots** will be used to encourage kids to look for help and promote agency; the free version is enough, although parents may benefit of getting a subscription.
